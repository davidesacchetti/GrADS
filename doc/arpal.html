GrADS 2.2.5: ARPAL additions

This page lists the features added to GrADS 2.2.5 in the ARPAL fork (github.com/davidesacchetti/GrADS, branch 2.2.5), with the release in which each one appeared (2.2.5-N). The complete list of changes is in the files ChangeLog and changelog_2.2.5.txt of the source tree. Use q config to see the installed release.

Display (Cairo plug-in)

  • Widgets on the Cairo display (2.2.5-1..5): buttons (draw button, redraw button, set button), drop menus with cascades (draw dropmenu, set dropmenu), rubber banding (set rband), dialog boxes (q dialog) and screen save/show/free, before available only with the X11 display. The submenus open after the pointer rests about 300 ms on an item, and the menus are drawn without flickering.
  • q pos pointer (2.2.5-6): position of the mouse without waiting for a click; -999.9 outside the window.
  • q pos keys (2.2.5-12): key presses in the graphics window (class 4, X keysym: arrows 65361-65364). Without keys the keys are ignored as before.
  • set rband line (2.2.5-16): with the X11 display the line goes from the click to the pointer in every direction.
  • screen dump / screen load (2.2.5-8): saved screens written to PNG files and read back, also in another session; screen show scales the buffer to the window. Since 2.2.5-13 the saved screens are pixmaps on the X server, so screen show is fast also with a remote display (ssh -X).
  • Double buffering (set dbuff, swap, 2.2.5-10, 2.2.5-11): no memory leak at each swap; when the window is resized the hidden buffer is recreated and the displayed image is redrawn to scale.
  • set gxout grfill (2.2.5-8): 3-5 times faster on large grids, same image.
  • -d option (2.2.5-6): the choice of the display plug-in (for example grads -d X11) works again.
  • screen save/show with X11 (2.2.5-18): after the window has been resized screen show scales the saved screen to the window (XRender, done by the X server) and screen save saves the whole window, as with Cairo.
  • Window title (2.2.5-17): command line option -T title and command set wtitle title, with the Cairo and X11 displays, without external tools (xprop, xdotool). The display plug-ins have the new optional entry gxdtitle.
  • Mouse pointer (2.2.5-20): while q pos reads the mouse (also with nowait and pointer) the pointer on the window is the crosshair of the desktop cursor theme (libXcursor, loaded at run time; the core X crosshair without it); back to the normal pointer after the awaited click and at the command prompt. Cairo and X11 displays, new optional plug-in entry gxdcurs.

Functions and commands

  • collect with all dimensions fixed and coll2gr() with only X varying (2.2.5-1): 1-D sections, oblique sections of variables not depending on Z, define of X-Z sections.
  • coll2gr() (2.2.5-16): the X axis of the result is linear, so it can be combined with the grids of the files (e.g. coll2gr(1,-u)-lev).
  • bilin(), bicub() (2.2.5-7): bilinear and bicubic interpolation at a point (ARPAL extension libdvd.gex).
  • percentile(expr,e=e1,e=e2,p) (extension libperc.gex, 2.2.5-19): for each grid point the value of rank ceil(p/100*n) among the n defined members. About 2.7 times faster (selection instead of sorting), the undefined members are skipped (before they were sorted as numbers), no crash with define as first command.
  • tshift(expr,minutes) (extension libdvd.gex, 2.2.5-19): moves the time axis of the result by the given minutes, e.g. d tshift(prec,-90) to draw a histogram half a step back. The shift is applied to a copy: before it moved for good the time axis of the variable (for example of a defined variable used again afterwards). Note: define does not keep the shifted time axis.
  • shift(expr,dx,dy), raigrid(expr,radius), bterp(expr,grid) (extension libdvd.gex, 2.2.5-19): undefined points taken from the mask, memory released at every call; bterp checks that both grids vary in lon and lat.
  • q xy2gr, q w2gr (2.2.5-16): no longer crash GrADS on plots with time on one axis (time-height, time-longitude).
  • q config (2.2.5-9): a line with the complete release, for example Release 2.2.5-12.fc44.
  • q gxconfig (2.2.5-14): the lines are also returned in result, so a script can find out which display plug-in (Cairo or X11) the session is using.
  • reset, reinit (2.2.5-15): the graphics plug-ins and the window geometry given on the command line (-d, -g) are kept (before, q gxconfig showed an empty display name after a reset).

Data

  • tif2ctl (2.2.5-13): descriptor files to open GeoTIFF rasters, read directly when possible, otherwise converted with GDAL.
  • Map files hres_world, lres_world, mres_world installed in the GrADS data directory (2.2.5-2), to be used with set mpdset.

GradsPy

  • result() with the regridding functions (re, re2) no longer crashes and returns the coordinates of the regridded grid (2.2.5-5).
