reinit

This command returns GrADS to its initial state. It closes all open files, releases all defined variables, and resets all graphics settings to their defaults. The graphics plug-ins and the window geometry chosen on the command line (-d, -g) are kept (GrADS 2.2.5-15, ARPAL: before, q gxconfig showed an empty display name after a reinit).

Usage Notes

See the section of the User's Guide on reinitialization of GrADS.
