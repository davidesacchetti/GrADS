screen

screen save|show|free num
screen dump|load num file.png

This command allows the user to save the contents of the display window into a buffer in memory, and also to restore a saved buffer to the current display at any time. This command will work in double buffer mode and was written to facilitate animations when working interactively with GrADS. The options are as follows:

    save
      Saves the contents of the display screen into memory as buffer # num.

    show

      Draws the contents of buffer # num to the screen.

    free

      Releases the contents of buffer # num from memory.

    dump

      Writes buffer # num (from a previous screen save) to the PNG file file.png.

    load

      Reads the PNG file file.png (for example written by screen dump in another session) into buffer # num, to be drawn with screen show.

Usage Notes

This command does not work in batch mode. With the Cairo display it works since version 2.2.5; dump and load are available only with the Cairo display.

If the window size differs from the one of the saved buffer (window resized, or buffer loaded from a file), screen show scales the buffer to the window. After a screen show, when the window is resized the last buffer shown is drawn again, scaled to the new size, together with everything drawn after it.

Examples

'd t'
'screen save 1'
'screen dump 1 background.png'
and in another session: 
'screen load 1 background.png'
'screen show 1'
