set dbuff

set dbuff on|off|hold|release

Sets double buffer mode on or off. This allows animation to be controlled from a script. The clear command also sets double buffer mode off.

Usage Notes

See swap. In version 2.2.5 (ARPAL) double buffering works with the Cairo display also when the window is resized.

set dbuff hold and set dbuff release (ARPAL 2.2.5-20, Cairo and X11 displays): after hold the drawing goes to an off-screen copy of the window, which release puts on the window in one operation. A redraw made of several steps, for example screen show followed by lines, marks and strings drawn over the restored image, then appears at once, without flickering. Unlike set dbuff on/off, hold and release do not clear the window and keep the widgets (buttons, drop menus); in double buffer mode they do nothing. release without hold does nothing, so a script can use it to check whether GrADS knows the command (older versions give a SET error).
