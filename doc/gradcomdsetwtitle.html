set wtitle

set wtitle title

Sets the title of the graphics window (and its icon name) to title, the rest of the command line with its case. (ARPAL, GrADS 2.2.5-17)

Usage Notes

  1. The default title is "GrADS version". To have the title already when the window opens use the command line option -T title; set wtitle changes it afterwards, for example from a script.
  2. Works with the Cairo and X11 display plug-ins; it is ignored in batch mode and by display plug-ins that do not provide it (no error).
  3. No external tool (xprop, xdotool) is needed.

Examples

grads -l -T "ecita_2026111806 SKEW" -c "run essl_skew.gs ..."

'set wtitle ecita_2026111806 E-W'
