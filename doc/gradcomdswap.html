swap

swaps buffers, when double buffer mode is on

Usage Notes

In version 2.2.5 (ARPAL), with the Cairo display, swap copies the hidden buffer to the window in a single operation, without leaking memory, and clears the hidden buffer (like clear, but without turning double buffering off). When the window is resized the hidden buffer is recreated with the new size and the image on display is redrawn to scale.

Do not use clear inside an animation loop: it turns double buffering off and the drawing goes to the visible window (flickering). A common pattern is to save a background with screen save and to draw it with screen show at each frame: 

'd background_field'
'screen save 99'
'set dbuff on'
while (...)
  'screen show 99'
  ... draw the frame ...
  'swap'
endwhile
