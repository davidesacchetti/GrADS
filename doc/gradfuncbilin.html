bilin(), bicub()

These functions interpolate an expression at a point given by longitude and latitude. The syntax is:

    bilin(expr, lon, lat)
    bicub(expr, lon, lat)

    expr     any valid GrADS expression
    lon      longitude of the point
    lat      latitude of the point

bilin performs a bilinear interpolation from the 4 grid points around the point. bicub performs a bicubic interpolation (Keys kernel, Catmull-Rom) from the 16 grid points around the point.

Usage Notes

  1. These functions are ARPAL extensions in the libdvd.gex library (GrADS 2.2.5-7). They are available when the ARPAL extensions are installed and listed in the user defined extension table (UDPT).

  2. Longitude and latitude must be fixed in the dimension environment. The result varies like the other dimensions: a vertical profile (Z varying), a time series (T varying), a Z-T section or a single value. It can be displayed or defined like any other GrADS result.

  3. With bilin, if one of the grid points with a non zero weight is missing the result is undefined. With bicub, where one of the 12 outer points is missing (domain border, undefined values) the bilinear interpolation is used.

  4. The reference grid is the one of the file of the first variable in expr (for example t.2, or a defined variable), otherwise the default file. Global grids wrapping in longitude are supported.

  5. Unlike set lon / set lat alone, which select the nearest grid point, these functions give a value that changes smoothly with the position of the point: they are used for the vertical profiles of the skew-T diagrams.

Examples

Vertical profile of temperature (in Celsius) at a point, with smooth interpolation: 

set lon 8.93
set lat 44.41
set lev 1000 200
define temp = bicub(t-273.16, 8.93, 44.41)
d temp
Time series of the bilinear interpolation of the 2-m temperature: 
set lon 8.93
set lat 44.41
set t 1 last
d bilin(t2m, 8.93, 44.41)
