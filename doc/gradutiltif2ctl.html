tif2ctl

tif2ctl [options] file.tif [file.ctl]

tif2ctl is an external utility (GrADS 2.2.5-13, ARPAL) that writes a data descriptor file to open a GeoTIFF raster in GrADS.

GrADS cannot read TIFF files, but an uncompressed GeoTIFF in geographic coordinates, organized in contiguous strips, is a plain binary grid preceded by a header. For such a file tif2ctl writes a descriptor that points directly to the .tif, without copying the data:

  • FILEHEADER is the offset of the first strip of data;
  • OPTIONS yrev, because the rows of a GeoTIFF go from north to south, and little_endian or big_endian according to the byte order of the file;
  • XDEF and YDEF are the centers of the cells, computed from the GeoTIFF tags (ModelPixelScale, ModelTiepoint, PixelIsArea or PixelIsPoint);
  • UNDEF is the nodata value of the file (GDAL_NODATA tag);
  • the data type is given in the units field of the variable (see VARS): 99 for Float32, -1,40,1 for Byte, -1,40,2 for UInt16, -1,40,2,-1 for Int16, -1,40,4 for Int32.

In the other cases the file is converted with GDAL into a raw binary file (.bin, ENVI format, with its .hdr) next to the descriptor:

  • compressed data, tiled images, bands interleaved by pixel, bands of different types: gdal_translate;
  • data types not supported by GrADS (Int8, UInt32, Float64, ...): gdal_translate -ot Float32;
  • projected coordinates (UTM, Lambert, ...) or rotated grids: gdalwarp to a regular lat-lon grid (EPSG:4326), Float32.
The TIFF and GeoTIFF tags are read by tif2ctl itself (python 3 standard library): GDAL is needed only for the conversions.

The options are:

    -v name
      Name of the variable. The default is the name of the file, in lower case, without the characters not allowed by GrADS.
    -u value
      Undefined value. The default is the nodata value of the file, otherwise -9.99e8.
    -b vars|levels|times
      How to describe a file with more than one band: one variable for each band (default, names name1, name2, ...), one variable with the bands as Z levels (1, 2, ...), or one variable with the bands as times.
    -t time
      Initial time of TDEF (default 00z01jan2000).
    -i increment
      Time increment of TDEF (default 1dy), used with -b times.
    -c
      Always convert with GDAL, also when the file could be read directly.
    -s srs
      Reproject to this coordinate system with gdalwarp (for example EPSG:4326).
    -r method
      Resampling method of gdalwarp (default near; bilinear, cubic, average, ...).
    --res degrees
      Grid spacing of the reprojected grid, in degrees (default: chosen by gdalwarp).
    -o dir
      Directory where the descriptor (and the converted file) are written.
The descriptor is file.ctl in the current directory unless a name is given. The DSET record uses the ^ notation, so the descriptor and the data can be moved together.

Usage Notes

  1. A descriptor pointing to the .tif stays valid only as long as the file is not rewritten: if the GeoTIFF changes (for example a new version of the same product), run tif2ctl again.

  2. A GeoTIFF has no time information: the TDEF record is a placeholder that can be changed with -t and -i, or edited by hand. To aggregate a series of GeoTIFF files with the same grid, write the descriptor for the first one and use a template in the DSET record, adding template to OPTIONS (all the files must have the same header length, which is true for files written by the same program).

  3. Reprojection with gdalwarp resamples the data: with the default near method the values are not changed, but a cell may be moved to the nearest cell of the new grid. Use -r bilinear for continuous fields.

  4. In GrADS the descriptor of a GeoTIFF is opened like any other binary data set: open file.ctl.

Examples 

$ tif2ctl dem_liguria.tif
tif2ctl: dem_liguria.tif letto direttamente (FILEHEADER 384)
tif2ctl: scritto dem_liguria.ctl

$ cat dem_liguria.ctl
DSET ^dem_liguria.tif
TITLE dem_liguria
UNDEF -9999
FILEHEADER 384
OPTIONS yrev little_endian
XDEF 40 LINEAR 7.05 0.1
YDEF 20 LINEAR 43.05 0.1
ZDEF 1 LINEAR 1 1
TDEF 1 LINEAR 00z01jan2000 1dy
VARS 1
dem_liguria     0 99 dem_liguria.tif
ENDVARS

$ tif2ctl -v rain -r bilinear radar_utm32.tif radar.ctl
tif2ctl: radar_utm32.tif da convertire: proiezione non geografica
tif2ctl: gdalwarp ... radar_utm32.tif radar.bin
tif2ctl: scritto radar.ctl

$ tif2ctl -b times -t 00z19nov2026 -i 1hr rain_24bands.tif
